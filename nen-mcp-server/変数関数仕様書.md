# 変数関数仕様書

本プロジェクトで使用される主要な変数・関数の定義と依存関係を記録します。

## 1. エントリーポイント (main.rs)
- `main()`: サーバーのメインループ。標準入力から JSON-RPC リクエストを読み込み、処理する。
    - 依存: `mcp::JsonRpcRequest`, `mcp::JsonRpcResponse`, `mcp::InitializeResult`
    - 影響: プログラム全体の動作
- `fix_windows_console()`: Windows環境において、コンソールの入力および出力コードページを UTF-8 (65001) に設定する。
    - 依存: `windows-sys::Win32::System::Console::{SetConsoleOutputCP, SetConsoleCP}`
    - 影響: Windowsでの標準入力の文字化け防止

## 2. MCP プロトコル定義 (mcp.rs)
### 構造体
- `JsonRpcRequest`: JSON-RPC 2.0 リクエスト形式。
    - `jsonrpc`: "2.0" 固定。
    - `id`: リクエスト ID。
    - `method`: 実行するメソッド名。
    - `params`: メソッドのパラメータ。
- `JsonRpcResponse`: JSON-RPC 2.0 レスポンス形式。
    - `jsonrpc`: "2.0" 固定。
    - `id`: リクエスト ID。
    - `result`: 成功時の結果（Option）。
    - `error`: 失敗時のエラー（Option）。
- `JsonRpcError`: エラー情報。
    - `code`: エラーコード。
    - `message`: エラーメッセージ。
- `InitializeResult`: `initialize` メソッドの実行結果。
    - `protocol_version`: MCP プロトコルのバージョン。
    - `capabilities`: サーバーの機能。
    - `server_info`: サーバー名とバージョン。
- `ServerCapabilities`: サーバーが提供する機能のフラグ（現在は `tools` をサポート）。
- `ToolCapabilities`: ツールの機能フラグ。
- `ToolListResult`: ツール一覧のレスポンス形式。
- `Tool`: ツールの定義。
- `CallToolRequest`: ツール実行のリクエスト形式。
- `CallToolResult`: ツール実行のレスポンス形式。
- `ToolContent`: ツールの出力内容（現在は Text のみ）。
- `ServerInfo`: サーバー情報。

### 実装 (impl JsonRpcResponse)
- `success(id: Value, result: Value) -> Self`: 成功レスポンスを生成。
- `error(id: Value, code: i32, message: &str) -> Self`: エラーレスポンスを生成。

## 3. 文字コード処理 (encoding.rs)
- `decode_to_utf8(bytes: &[u8]) -> (String, &'static str)`: `chardetng` と `encoding_rs` を使用してバイト列を UTF-8 文字列に変換する。
    - 引数: `bytes`: 変換対象のバイト列。
    - 返り値: デコードされた文字列と、検出されたエンコーディング名のタプル。
    - 依存: `chardetng`, `encoding_rs`
    - 影響: `safe_read` ツールのテキスト変換精度。
    - **テスト**: `tests::test_decode_sjis` で Shift-JIS のデコードを検証。

## 4. ツール共通処理 (tools/mod.rs)
- `validate_and_canonicalize(path: &str) -> anyhow::Result<std::path::PathBuf>`: パスが存在するか、ファイルであるかを確認し、正規化（絶対パス化）して返す。Windows環境において UNC パスの接頭辞 `\\?\` を付与しないように `dunce` を使用する。
    - 引数: `path`: 検証対象のパス文字列。
    - 返り値: 正規化された `PathBuf`（Result型）。
    - 依存: `dunce::canonicalize`
    - 影響: `safe_read`, `inspect_file`, `read_hex` でのパス検証ロジックを共通化。

## 5. ツール実装 (tools/safe_read.rs)
- `safe_read(path: &str, range: Option<[usize; 2]>, tail: Option<usize>) -> anyhow::Result<(String, &'static str)>`: ファイルをバイナリで読み込み、自動判別でテキスト化して返す。
    - 引数:
        - `path`: ファイルパス。
        - `range`: 読み込み開始・終了バイト位置（オプション）。
        - `tail`: 末尾から読み込むバイト数（オプション）。
    - 返り値: デコードされたテキストとエンコーディング名のタプル（Result型）。
    - 依存: `encoding::decode_to_utf8`, `tools::validate_and_canonicalize`
    - 影響: MCP ツール `safe_read` の実行結果。

## 6. パーサー処理 (parser/mod.rs)
- `get_language(extension: &str) -> Option<tree_sitter::Language>`: ファイル拡張子に対応する `tree-sitter` の言語定義を返す。
    - 引数: `extension`: ファイル拡張子。
    - 返り値: `tree_sitter::Language` のオプション。
    - 依存: `tree-sitter-rust`, `tree-sitter-python`, `tree-sitter-c-sharp`
    - 影響: `get_outline` ツールの言語判別。
    - **テスト**: `tests::test_get_language` で主要な拡張子の判別を検証。

## 7. アウトライン抽出 (tools/get_outline.rs)
- `get_outline(path: &str) -> anyhow::Result<String>`: 指定されたファイルのアウトライン（関数やクラスの定義）を抽出し、JSON 形式で返す。
    - 引数: `path`: ファイルパス。
    - 返り値: `[{"line": u32, "kind": String, "name": String}]` 形式の JSON 文字列（Result型）。
    - 依存: `tools::safe_read::safe_read`, `parser::get_language`
    - 影響: MCP ツール `get_outline` の実行結果。

## 8. ファイルインスペクト (tools/inspect_file.rs)
- `inspect_file(path: &str, search_query: Option<String>) -> anyhow::Result<String>`: ファイルのメタデータ取得とキーワード検索を行い、JSON 形式で返す。
    - 引数:
        - `path`: ファイルパス。
        - `search_query`: 検索キーワード（オプション）。
    - 返り値: `InspectResult` 構造体をシリアライズした JSON 文字列（Result型）。
    - 依存: `encoding::decode_to_utf8`, `chrono`, `tools::validate_and_canonicalize`
    - 影響: MCP ツール `inspect_file` の実行結果。

## 9. ヘキサダンプ (tools/read_hex.rs)
- `read_hex(path: &str, offset: Option<u64>, length: Option<usize>) -> anyhow::Result<String>`: ファイルの指定範囲を読み込み、ヘキサダンプ形式の文字列を返す。
    - 引数:
        - `path`: ファイルパス。
        - `offset`: 読み込み開始位置（オプション）。
        - `length`: 読み込むバイト数（オプション）。
    - 返り値: 伝統的なヘキサダンプ形式の文字列（Result型）。
    - 依存: `tools::validate_and_canonicalize`
    - 影響: MCP ツール `read_hex` の実行結果。
    - **テスト**: `tests::test_read_hex_logic` でヘキサダンプの出力形式を検証。
