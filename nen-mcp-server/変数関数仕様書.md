# 変数関数仕様書

本プロジェクトで使用される主要な変数・関数の定義と依存関係を記録します。

## 1. エントリーポイント (main.rs)
- `main()`: プログラムのエントリーポイント。CLI 引数を解析し、MCP サーバーとして動作するか、CLI サブコマンドを実行するかを判定する。
    - 依存: `Cli`, `run_mcp_server()`, `handle_tool_call()`
    - 影響: プログラム全体の動作
- `run_mcp_server()`: サーバーのメインループ。標準入力から JSON-RPC リクエストを読み込み、処理する。
    - 依存: `mcp::JsonRpcRequest`, `mcp::JsonRpcResponse`, `mcp::InitializeResult`, `handle_tool_call()`
    - 影響: MCP サーバーとしての動作
- `handle_tool_call(name: &str, arguments: Value) -> CallToolResult`: ツールの実行ロジックを共通化した関数。MCP と CLI の両方から呼び出される。
    - 引数:
        - `name`: ツール名。
        - `arguments`: ツールに渡す引数（JSON Value）。
    - 返り値: 実行結果を含む `CallToolResult`。
    - 依存: `tools::safe_read`, `tools::get_outline`, `tools::inspect_file`, `tools::read_hex`
    - 影響: すべてのツールの実行結果
- `fix_windows_console()`: Windows環境において、コンソールの入力および出力コードページを UTF-8 (65001) に設定する。
    - 依存: `windows-sys::Win32::System::Console::{SetConsoleOutputCP, SetConsoleCP}`
    - 影響: Windowsでの標準入力・出力の文字化け防止

### CLI 定義
- `Cli`: `clap` を使用したコマンドライン引数の構造体。
    - `mcp`: MCP サーバーモードで実行するフラグ。
    - `command`: 実行するサブコマンド（オプション）。
- `Commands`: CLI のサブコマンド定義。
    - `SafeRead`: `safe_read` ツールを実行。
    - `GetOutline`: `get_outline` ツールを実行。
    - `InspectFile`: `inspect_file` ツールを実行。
    - `ReadHex`: `read_hex` ツールを実行。
